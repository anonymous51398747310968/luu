# イラスト制作と組み込み

## 世界観

ポムポム村の百年に一度の星降り祭から、お菓子の町、魔女の沼、凍った湖、星の階段、月の城へ向かう物語。可愛いおとぎ話の見た目と、喪失・孤独・声を取り戻す物語が同居するため、柔らかさを保ちながら夜と空虚の場面では深い藍色を使います。

絵柄は、水彩とガッシュの絵本調。暖かい紫褐色の細い輪郭線、紙の質感、星・月・お菓子の装飾を共通にしました。キャラクターは約3頭身の全身像、背景は人物を置く中央の床面を確保した風景です。

生成にはユーザー承認済みの利用可能な画像生成ツールを使用しました。ツールにモデルを指定・確認する機能がないため、GPT Image 2.5としての記録はしていません。

## 差分と使う場面

| コード | 内容 | 主な用途 |
| --- | --- | --- |
| `n` | 基本 | 会話、探索、町での待機 |
| `h` | 喜び・笑顔 | 再会、冗談、商店、仲間紹介 |
| `c` | 悲しみ・涙 | 告白、別れ、低HP |
| `a` | 決意 | 対決、敵として登場する人物 |
| `o` | 驚き | 真実の発覚、危機 |
| `s` | 歌う | ミーナの歌、ルゥの声と終盤の合唱 |

## 敵と背景

24種類の敵すべてに生成画像を割り当てています。うち20種類は敵専用画像、ショコラ・月の騎士・ステラ・ププは人物画像を使います。大きな翼や腕を持つ白鳥・ゴーレム・巨人、最後の「からっぽ」は単独画像から書き出し、隣の絵の混入を避けました。

18背景: 村の昼・夜・月のひび、タイトル、森・森の奥、お菓子の町、塔、沼、湖、丘、星の階段、月の城門、玉座・暗い玉座、空虚、セピアの記憶、地図。地図は生成した風景の上に既存の地点・道・ラベル・操作領域を残しています。

## サイズ・透過・読み込み

- 全身人物は384×480、足元を下から20pxの位置に統一。人物ごとの表情セットは共通倍率で書き出します。画像枠と左右の位置は表情を変えても動きません。
- 敵は512×512、仲間アイコンは96×96。人物と敵は透過WebPで、四辺に透明な余白を確保しています。
- 背景は主に768×512。暗い玉座と空虚は1024×768です。表示には`object-fit: cover`、人物には`contain`を使い、立ち絵を切り抜きません。
- タイトル背景は約158KB。登場した人物だけ表情を先読みし、全世界の画像や制作元シートを最初に読み込むことはありません。
- 実行用画像の合計は約10MB。約50MB台の制作元シートは再編集用で、ゲームから読み込みません。

`assets/manifest.json`には画像の対応と生成元画像のSHA-256、`assets/source-manifest.json`には切り出し位置・登録設定・共有差分を記録しています。`tools/export-art.cjs`は画像の切り出しと圧縮だけを行い、表情や衣装の描き替えは画像生成ツールで行っています。

# 検証記録

実行日: 2026-10-04。ChromiumをPlaywrightから起動し、ローカルHTTPサーバーで実際のHTMLを読み込みました。

最終実行結果: 自動検証13件すべて成功。生成元から再書き出した実行用画像236ファイルもSHA-256が一致しました。コードレビューでは重大な問題の指摘はありませんでした。

## 自動検証

`npm test`で次を確認します。

- HPを増やす装備を外した際、表示と次の戦闘が新しい最大HPを超えない。
- 不正なセーブに「つづきから」を表示しない。元のダンジョンキューと分岐展開後のキューは読み込める。
- メェメの保存が失敗した際、成功したという表示をしない。
- 320×568、390×660、568×320で、ボスと予告が画面内に収まり、横方向にはみ出さない。
- 表情を切り替えても立ち絵の表示位置と枠のサイズが変わらない。
- 全敵に生成画像があり、画像が読み込める。ストーリー内の人物・表情と全画像ファイルの対応が揃っている。
- 元のシーンデータを正規化したSHA-256と比較し、本文・選択肢・進行指示が維持されている。
- 320×568で攻撃・スキル・防御・アイテムの4ボタンをスクロールなしで押せる。
- 敵の対象選択、アイテムによる復活、防御、敗北後の再挑戦、ダンジョンのセーブ再開が動作する。
- 最初はタイトル背景だけを要求し、制作元シートを要求しない。
- 5つのダンジョンをブラウザ上で進め、エンディング・復活後のマシュ・ルゥの声・クリア保存とその再開まで到達する。
- 人物と敵の書き出しサイズが揃い、四辺の透明余白が保たれている。

通しプレイの自動検証は、進行・画面・保存の確認用に戦闘能力を上げています。約1時間の通常プレイの難易度評価には使っていません。製品の戦闘エンジンと敵・仲間の能力値は維持しています。
